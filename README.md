# E-commerce Analytics Dashboard

## Overview

An interactive Power BI dashboard developed to analyze E-commerce
profitability, customer behaviour, operational performance and value leakage.

## Business Problem

The objective was to understand what drives profitability and identify
areas where revenue and contribution margin are being lost through:

- Product returns
- Discounts and promotions
- Stock availability
- Fulfillment performance
- Customer behaviour
- Regional performance

## Tools & Technologies

- Power BI
- DAX
- Power Query
- Data Modelling
- ZoomCharts

## Dashboard Pages

### 01 — Profitability Overview

Analyzes:
- Net Sales
- Contribution Margin
- Contribution Margin %
- Lost Sales Value
- Product profitability
- Regional profitability
- Promotion performance
- Discount impact

### 02 — Customer & Cohort Analysis

Analyzes:
- Customer segments
- Acquisition channels
- Customer cohorts
- Lifecycle stages
- Sales channels
- Cohort-age profitability

### 03 — Operations & Value Leakage

Analyzes:
- Return losses
- Return rates
- Lost sales
- Fulfillment performance
- Fulfillment costs
- Inventory availability
